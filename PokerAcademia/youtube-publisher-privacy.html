Poker Academia Shorts Publisher — Privacy Policy

Last updated: November 19, 2026

Summary: the Shorts Publisher uses YouTube API Services to upload Poker Academia's own videos to the Poker Academia YouTube channel. Its only user is the channel owner. It stores one authorization token and the IDs of the videos it uploads, nothing else. It does not use cookies, does not collect data about viewers and does not share any data for advertising.

1. Use of YouTube API Services

Poker Academia Shorts Publisher (the "Tool") uses YouTube API Services. By authorizing the Tool, you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy (http://www.google.com/policies/privacy).

2. Who uses the Tool

The Tool is an internal tool of Poker Academia. Its only user is the owner of the Poker Academia YouTube channel (@Poker-Academia), who authorized it with their own Google account. It is not offered to the public and cannot be used to access any other account or channel.

3. Information the Tool accesses, collects and stores

InformationWhyWhere and how long
OAuth 2.0 refresh token for the channel owner's Google account, scope youtube.upload onlyUpload approved videos to the Poker Academia channelEncrypted secret in the private cloud environment that runs the Tool, kept until access is revoked, then deleted within 7 days
Video ID and URL returned by the API for each video the Tool uploadsPublication log, so a video is never uploaded twiceInternal publication log, kept while the video is online, deleted within 30 days after the video is removed
Video file, title, description, tagsThe content being uploadedCreated by Poker Academia, not obtained from YouTube

The Tool does not access, collect or store: viewers' data, comments, subscribers, channel analytics, watch history, other channels' data, or any other information from the channel owner's Google account.

4. How the information is used and shared

  • The information above is used only to upload Poker Academia's own videos and to keep the publication log.
  • It is never sold, never used for advertising and never shared with third parties, except the infrastructure providers that host and run the Tool on our behalf, under confidentiality obligations.
  • No data obtained through YouTube API Services is combined with other data sources.

5. Cookies and device data

The Tool has no public interface. It does not place, read or store cookies or any other information on users' devices or browsers.

6. Revoking access and deleting data

  • Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions.
  • After revocation, the stored token stops working and is deleted from our environment within 7 days.
  • To request deletion of any stored data, write to pokeracademia.contact@gmail.com. We delete it within 7 days and confirm by email.
  • Data obtained through YouTube API Services that is no longer needed is deleted, and in any case is not kept beyond the periods above.

7. Security

The token is stored as an encrypted secret, never in source code or in files, and is only readable by the process that performs the upload. All calls to Google APIs use HTTPS.

8. Changes

We will update this page, and its date above, before any change in the way the Tool uses YouTube API Services.

9. Contact

Poker Academia — pokeracademia.contact@gmail.com. We answer within 30 days.
